# AiLGNS 观测站

每天自动抓取并展示：**动态奖励（增长/网络/共识）· 当天单价 · P1–P7 各等级所得 · 链上协议状态**。

---

## 页面里有什么（两部分，更新方式不同）

| 区块 | 内容 | 更新方式 |
|---|---|---|
| **链上实时** | 公开买入开关（实时探测）· 当前区块 · AiLGNS/DAI 池现价 · 协议储备 | **每 30 秒自动刷新**，浏览器直读 Anubis 链 |
| **动态奖励** | 最新一期发放合计、单价、P1–P7 各等级所得、14 天历史 | 由定时任务更新（每天变一次）|

**「公开买入」这一栏是实时探测出来的**：页面直接去链上模拟一次买入，被拒绝就显示「未开放」，一旦通过就变绿并弹出提示。
这样即使你不在电脑前，只要页面开着，就能第一时间看到买入开放。

## 方式 A（推荐先用这个）：双击打开，零安装

直接双击文件夹里的 **index.html**，用浏览器打开就能看。

- **不需要安装任何东西**，不需要 Node.js，不需要开服务器
- 页面里内置了抓取当时的数据快照，标注为「数据源：内置快照」
- 双击打开时数据**不会自动更新**（浏览器安全限制，本地文件不能联网读同目录文件）

想看最新数据时，重新生成一次快照即可（见方式 B 或 C）。

---

## 方式 B：本机跑，实时更新

需要装 **Node.js 18 或更高版本**（https://nodejs.org/zh-cn ）。

装好后，在本文件夹里打开终端（Windows：在文件夹地址栏输入 cmd 回车），执行：

    node server.mjs

然后浏览器打开： **http://localhost:8787**

- 启动时会自动抓一次数据（此时页面会标注「数据源：实时」）
- 右上角「刷新」按钮点一下立刻重新抓
- 页面每 30 分钟自动重读一次

停止：在终端按 Ctrl + C。

> ⚠️ 如果提示「node 不是内部或外部命令」，说明还没装 Node.js，用方式 A 或方式 C。

## 方式 C：挂到 GitHub Pages（不用开电脑，手机随时看）

**这是唯一能"每天自动更新"的方案**：GitHub 每 4 小时自动帮你抓一次。

### 第 1 步：建仓库并上传

> ⚠️ **最容易踩的坑**：拖拽时要**全选文件夹里的内容**（Ctrl+A），**不要拖整个文件夹**。
> 拖整个文件夹的话，网页会变成 `/仓库名/index.html`，打不开。

**怎么打开文件所在位置**：按 Win+R，粘贴下面这行，回车 ——

    D:\codex\2026-09-08\ni\outputs\ailgns-monitor

然后在文件夹里按 **Ctrl+A** 全选，把所有文件和 .github 文件夹一起拖到 GitHub 的上传框里。


把本文件夹里的所有内容传上去：`index.html`、`collect.mjs`、`server.mjs`、`data.json`、`README.md`，
以及 `.github/workflows/update.yml`（这个文件夹默认隐藏，上传时要确认带上）。

### 第 2 步：开 Pages

仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 **main**、目录选 **/ (root)** → 保存。

等 1–2 分钟，地址是： https://你的用户名.github.io/仓库名/

### 第 3 步：允许机器人提交数据

仓库 → **Settings → Actions → General** → **Workflow permissions** → 选 **Read and write permissions** → 保存。

### 第 4 步：手动跑一次验证

仓库 → **Actions** → 左边选 `update-data` → 右边 **Run workflow**。

跑完回到 Pages 网址刷新即可。之后每 4 小时自动跑一次（北京时间 09:30 / 15:30 / 21:30 / 03:30）。

> GitHub 定时任务高峰期可能延迟几分钟到几十分钟，属正常。

## 关于「最新一期」

官方是 **T+1 公布**：某一天的名单在**第二天凌晨约 02:58（UTC+8）**公布，公布后还有 24 小时挑战期才能领取。

所以页面上「最新一期」的日期通常比今天早 1–2 天，这是正常的，不是抓取失败。

---

## 抓取失败怎么办

- 某个来源抓不到时，采集器会**尽量沿用上一次成功的快照**，页面不会变空白，顶部会提示哪一项失败
- 上游网站改版会导致解析失效，需要更新 `collect.mjs` 里的解析规则
- 终端里能看到具体失败原因
